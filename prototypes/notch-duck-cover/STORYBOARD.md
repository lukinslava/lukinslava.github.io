# Notch Duck — cover loop, v1

Обложка кейса на главной, ряд AI & side projects: ролик 16:10, на карточке
~300 px шириной, без звука, по кругу.

- **Message:** нотч оживает — утка здоровается, держит под рукой буфер, скриншоты и ссылки, убирает рабочий стол.
- **Format:** 1600×1000, 30 fps, 7,5 с, без звука, бесшовный цикл: ролик начинается и заканчивается закрытым нотчем.
- **Spine:** чёрный нотч сверху по центру. Он не уходит из кадра: растёт в панель, меняет форму и в конце снова сжимается в «таблетку».
- **Brand:** тёплый градиент обоев из ролика (`#F9D9A0` → `#F2A86A` → `#7D62A0`), чёрный нотч `#0B0B0B`, утиный жёлтый `#F7D548`; заголовок — Antonio белым, как у соседних типографических обложек.
- **Truthfulness:** утка и панели — настоящие кадры из ролика; иконки файлов и папку на шаге 04 перерисовываю, чтобы они могли лететь.
- **Bans:** никакого мелкого и русского текста в кадре (на карточке он нечитаем); без свечения; не слайдшоу из кадров ролика; нотч не исчезает.
- **Held frame:** 05 — последние ~1 с: закрытый нотч с зелёной точкой и название.

## Frame 1 — Notch

- scene: Тёплые обои macOS, сверху по центру — чёрный нотч; по столу разбросаны файлы
- duration: 1.0s
- transition_in: cut
- status: built

0,0–1,0 с. Тихое начало для бесшовного цикла: файлы стоят, нотч чуть «дышит» (scaleX 1 → 1,04).

## Frame 2 — Hello

- scene: Нотч вытягивается вниз в чёрную панель, из неё выглядывает утка
- duration: 1.6s
- transition_in: continuous
- status: built

1,0–2,6 с. Панель растёт вниз (expo.out, 0,5 с), утка «Кря! Я на месте» появляется с подскоком (back.out). Подпись утки обрезана — текста в кадре нет.

## Frame 3 — Hover

- scene: Панель становится шире — вкладки Clipboard, Screenshots, Links быстро сменяют друг друга
- duration: 1.6s
- transition_in: morph
- status: built

2,6–4,2 с. Панель перетекает в широкую (power3.inOut, 0,45 с). Содержимое меняется трижды по 0,4 с горизонтальным сдвигом — как переключение вкладок.

## Frame 4 — Tidy

- scene: Панель снова узкая, утка довольна; файлы со стола слетаются в папку 2026-10-11
- duration: 1.6s
- transition_in: morph
- status: built

4,2–5,8 с. Файлы по очереди летят по дуге в папку справа внизу (stagger 0,06 с, power2.in), папка подпрыгивает. В панели — утка «Готово!».

## Frame 5 — Title

- scene: Панель сжимается обратно в нотч, на нём загорается оранжевая точка и становится зелёной; слева крупно «Notch Duck»
- duration: 1.7s
- transition_in: morph
- status: built

5,8–7,5 с. Нотч сжимается (power3.inOut, 0,4 с), точка: оранжевая → зелёная. «Notch Duck» поднимается по буквам. Последняя секунда — удержание, затем склейка на кадр 01.
